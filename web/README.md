# TR3D Landing Page

The marketing site for TR3D — the white-label treadmill coaching engine. Built with React, TypeScript, Vite, Tailwind CSS v4, and lucide-react icons.

## Development

```bash
cd web
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a static production build to `dist/`, deployable to any static host (Vercel, Netlify, Railway, etc.).
